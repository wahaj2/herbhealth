# HerbHealth — Natural Wellness & Balanced Living

A full storefront + admin CRM for a herbal wellness brand, built with TanStack Start and Supabase. Adapted from an existing template, restyled with a green/gold botanical theme, and repopulated with an original herbal product catalog (essential oils, herbal teas, supplements, tinctures & tonics).

- **Storefront**: home, shop with filters, product detail with variants, cart, checkout (Cash on Delivery), order confirmation, about, contact & FAQ.
- **Admin CRM** at `/admin`: products, categories, orders, reviews, site content & offers, and newsletter subscribers.
- Swap in your own Supabase project (see `supabase/migrations`) and set `VITE_SUPABASE_URL` / your anon key to go live.
